# Visual Editor

Edit the keymap in [Keymap Editor](https://nickcoutsos.github.io/keymap-editor/) by Nick
Coutsos. Sign in with GitHub, install its GitHub app on `lilfeelz/keyboard`, then pick the repo
and branch. It reads and commits `config/totem.keymap` at the repo root.

[Start Keymap Editor ↗](https://nickcoutsos.github.io/keymap-editor/)

Its commits change only the ZMK copy. Carry layout changes into `DefaultConfig.swift` and the
kanata dotfile by hand (see the repo `AGENTS.md`).
